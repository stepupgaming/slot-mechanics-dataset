Free Games Feature

3 [SCATTER] trigger the Free Games Feature.
Initially we have to spin a 3 x 3 reel window to calculate
total number of free games. Played in one round.
Retrigger is not possible.
Wilds are sticky in free game, wilds will stick to the same
position with multiplier till last free game

Multiplier Box Feature

Above reels 2, 3 and 4 there are 3 boxes
On every spin each box may contain a multiplier
If a Wild appears below a box (on any position), it takes
the multiplier that appears in the box above
Multipliers on wild add to each other on same line.

Wilds are sticky in free game, wilds will stick to the same
position with multiplier till last free game. E.i. multiplier
for the sticky Wild is not changed.
