GAME OVERVIEW
Game Description (for Players)
Collect bounties in Cowboy Coins™.

This western-themed slot has symbols in keeping with the cowboy aesthetic that must form
matching combinations across the title’s six reels and 20 paylines to unlock a win.

The free spins round awards three respins that are reset every time a new symbol lands during the
bonus game. Here, a central board of wins is landed with four different features around the
outside offering multiple upgrades to increase their size. Dynamite multipliers give random
symbols and Money Bags award more cash prizes, Safes collect prizes, and Badges multiply all
wins gained so far!

Game Information
Base Game:

•   Base Game Feature : Coin Symbol must be present either with Payer/Collector Symbol or with both.
•   Coin Symbol and Collector Symbol comes with the multiplier on them, the collector symbol will
    collect all the multipliers present on Coin Symbols and add it's value with it's own multiplier.
•   Coin Symbol and Payer Symbol comes with the multiplier on them, the payer symbol will pay all the
    multipliers present on Coin Symbols that is, it will add it's own multiplier value to each of the coin
    symbol present.
•   The sum of all the multipliers present over the reel window is the total multiplier value for that screen.
•   The total multiplier value* total bet is the total win for BG feature.

Free Game:
•   When on screen 3 or more than 3 Scatter symbol appears over the reel window then FG is triggered.
•   When FG Round starts initially player is awarded with 3 spins.3 spins is the initial spin reset value.
•   Whenever any additional symbol comes over the reel window the spins are again reset to it's initial
    value.
•   On FG game has only money symbols, no ways win
•   The FG symbols that triggered the FG converts to either into Regular Coin Symbol and/or into Super
    Coin Symbol.
•   The mechanism for Collector/Super Collector Symbol, Payer/Super Payer is same in FG also as it was
    in base game
Game Information

•   The Double Booster/ Super Double Booster Symbol mechanism is that it randomly choses 2 to 5 coins
    and doubles their multiplier value present on them. The Super Double Booster doesn’t become dead
    after the spin instead it keeps on doubling the Coin Values with every passing spin.
•   The Multi Collector/Super Multi Collector Symbol mechanism is: It randomly selects a single coin
    symbol and collects that value multiple times ( 2 to 30 times) and added with it's own value.
•   The order of execution for the game is in anti clockwise direction that first left reel is executed then,
    bottom reel then, right reel and then top reel.
•   In the left/ right reel the execution order is top to bottom direction while in top/bottom reels the
    execution order is in left to right direction.
•   The sum of all the multipliers present over the reel window is the total muptiplier value for that screen.
•   When all the positions are filled, then game will stop and FG spins will become 0
