GAME OVERVIEW
Game Description (for Players)
Expand the reels in Mystery Of The Orient.

Set across 5×3 reels this stunning slot has symbols depicting coins, tigers, swords and more which
must form matching combinations across the grid to award a win. Multiplier wilds come to aid
the player in creating wins and increase the value of any wins gained.

Three Scatters award 15 free spins where reels can expand via an arrow symbol landing. As a
result, each reel will have an additional cell at the top of the grid, allowing more symbols to land.

Mystery symbols also hold the key to additional scatters and wild multipliers, making it easier for
players to unlock retriggers. There are also jackpot prizes present for players to win!
Game Information
17 symbols:

   •   11 Regular symbols
   •   1 Wild symbol, substitute all symbols except Free Spins Symbols
   •   1 Scatter.
   •   1 Free Spins symbol
   •   1 Mystery symbol
   •   1 Reel Size Increase symbol
   •   1 Additional Free Spins symbol



Screen overview:

   •   Screen size 3x5 for base game. On the free spins may grow up to 6x5
   •   Reel height is variable
   •   Bet multiplier 25
Game Information
Free Spins:

•   Same as on the base game plus some additional feature.
•   On each spin with RP on screen we determine the replacement symbol. This symbol will be used in all
    Replace symbols, RP, on the reel strips.
•   Then based on the height of the reel we determine which Reel Set to use for each separate reel.
      • There are 4 options:
      • Reel Set 1 for reels of height 3;
      • Reel Set 2 for reels of height 4;
      • Reel Set 3 for reels of height 5;
      • Reel Set 4 for reels of height 6;

Base Game:

•   After reels spin, if any Mystery symbol is present on the reels it gets transformed into wilds (plain or
    with multipliers), Scatter or jackpot
•   Wild Multipliers bear the multipliers that apply to the total win (win from scatters, jackpots or lines)
•   If 2 or more Multiplier Wilds appear onscreen, then the total multiplier value will be the sum total of
    the values on each multiplier Wild.
•   Multipliers of 1 are just wild and are not added to the total multiplier (i.e. if the multipliers are 25, 25, 1,
    the total multiplier is 50, not 51).
