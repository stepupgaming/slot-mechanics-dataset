GAME OVERVIEW
Game Description (for Players)



Ways, Wilds and Wins hit the dancefloor in 3 Dancing Moneys™.

This Asian-inspired slot depicts a fan fare of traditional symbols, from oriental lamps, fans and jars that must form a
matching combination across the slot’s 5x3 reels to unlock a win. Joining our monkey friends on the reels are three
vibrantly coloured gems, each having the ability to trigger a game-altering feature to help players claim the slot’s max
win of over 12,000x!

10 free spins are granted in the bonus round, where at least two modifiers will be active. These can increase the size of
the reels to become 5x5 in size, award more wilds or increase winning possibilities via a multiplier mechanic. Players
can be further awarded additional spins by landing additional gems that trigger more monkey features!
Game Information
Screen size:

   •   Screen size 5x3.
   •   243 ways left to right.
   •   Bet multiplier is x30.



20 Symbols:

   •   10 Regular symbols
   •   3 Bonus symbols
   •   3 Special symbols
   •   4 Wild symbol
Game Information
Base Game:

   •   To the left of the smiling monkey trio is 3 Dancing Monkeys’ game grid, holding 5-reels, 3-rows and a 243-
       ways to-win pay system. Matching symbols on 3 or more adjacent reels from the left creates a winning way.


Free Game:

   •   Free game has three different features that can be active by themselves or concurrently during a free game:
       WAYS, WILDS, and WINS. Each feature has its own triggering symbol and rules.
   •   Features are activated with some probability. These features can be triggered individually or concurrently.
   •   Once any free game feature (or combination of features) are active, non-active free game features can be
       triggered, become active, and be added to the current feature.
   •   When activated each feature gives 5 free spins.
Game Information
Free Game:


   •   WAYS. The game changes to a 5x5 MultiWay layout.
   •   WILDS. Extra WILD symbols appear on the reels.
   •   WINS. ALL WILDS are multiplying wilds
   •   Each combinations of features uses dedicated reels set
   •   If feature is activated it remains active till the end of Free Game
   •   Special Symbols (actually, Money Scatters)
         •   Appear only during Free Game
         •   Appears on all reels
   •   Extra FS add free spins to current FS session
