Game Description
(for Players)
Mind the gap when boarding this feature-filled London underground-
inspired slot.

Down The Rails is a 5×3 reel game with 20 paylines that boasts five
different random features that can be triggered during any base
game spin! The bonus also has five different variations of the free
spins round that can be gambled by the player to unlock the most
volatile bonus available End of the Line.

Characteristics and features
- All winning combinations pay from left to right on
selected paylines.
- All wins are multiplied by bet per line, only the
highest win is paid per line.
- When winning on multiple paylines, all wins are
added to the total win.
- Bonus wins are added to the payline win.
- Bets are made in coins.
- To control bets, user is able to change the value of a
coin in real currency.
- Balance, bets, wins are all displayed in both coins
and real currency at all times.

Random Spin Features
In the base game, at any spin, one of the following
features can be triggered randomly:
- Tunnel Vision - When the feature hits, Mystery
symbols hit randomly on the screen then all of them
transform into the same paying symbol. The Mystery
Symbol only appears during this feature.
- The Big Smoke - Whenever the features hits, one 3x3
colossal paying symbol or Bonus symbol is added to
the screen on reels 1, 2, 3 or 4. Then the game pays
according to the winning combinations with the
colossal symbol or triggers the Bonus.
- Wild Strike - Whenever the features hits, Wild
symbols are added to the screen in random positions.
