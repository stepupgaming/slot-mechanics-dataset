GAME OVERVIEW
Game Description (for Players)

Crown a champion symbol in The Knight King™.

Mythical adventure underpins this slot where symbols are made up of various
heroes, dragons and shields which are joined by a wild on the title’s 5×3 reels.
The Knight King™’s quest is filled with surprises and one symbol can be chosen
randomly during any spin to fill the entire screen in the base game.

At least three scatters are needed to award seven free spins. Here, one symbol
is randomly chosen as a special throughout the bonus round and every win
made increases its value, allowing prizes to dramatically increase in size.
Game Description (for Players)

Game Description (for Players)

Free game:
    •   Free game is triggered if 3 Scatters appear on base spin
    •   Before the Free Game session starts the special pay symbol is selected
        for the whole Free Game Session
    •   Reels set is chosen according to the special pay symbol selected

Bonus Boost:
    •   Bonus boost is tied to the Free Spins feature activation.
    •   Reels set for base spin is predefined and guarantees free game
        activation
    •   Free spins mechanics is the same as for regular game
