ABOUT THE GAME

Welcome to the tranquil world of Sleepy Grandpa, a farmer who yearns for hidden treasures… and naps. Sleepy Grandpa is a 5-reel, 4-row paylines game featuring valuable hidden Coins, farm animals and an exciting bonus game. The max win in this game is 10,000 times your bet, and can be reached in both the base game and the bonus game.

FEATURES

DIG FEATURE

When at least one Farmer symbol and at least one Dirt symbol land at the same time, the Farmer digs up the Dirt! A Coin with one of the possible values 1x, 2x, 3x, 5x, 10x, 25x, 50x, 75x, 100x, 250x, 500x, 1000x will be uncovered and added to the Farmer symbol.

One Farmer symbol per reel can land at the same time. If multiple Farmer symbols land each Farmer will dig up each Dirt symbol one time.

When all Dirt symbols have been dug up, all Farmer symbol values will be added together and finally multiply the player’s bet to form the payout.

TRACTOR FEATURE

If a Farmer symbol or a Gold Farmer symbol lands in the grid but no Dirt symbols land at the same time, there is a chance to trigger the Tractor feature. The Tractor feature will plow the field and remove all symbols except any Bonus symbols and Farmer/Gold Farmer symbols that were already present in the grid. The Tractor will leave 1 - 10 Dirt symbols behind it, which will activate the Dig feature.

The Tractor feature is present in both the base game and the bonus game.

BONUS GAME

Land BONUS scatter symbols at the same time in the base game to activate the bonus game.

3 BONUS scatter symbols will award 10 free spins

4 BONUS scatter symbols will award 12 free spins

5 BONUS scatter symbols will award 15 free spins

Only one BONUS scatter symbol can land on each individual reel.

In the bonus game there is a chance the Gold Farmer symbol lands! A Gold Farmer symbol activates the Dig feature if at least one Dirt symbol lands at the same time. The Gold Farmer will immediately become sticky and stay in the same position throughout the entire bonus game. Only one Gold Farmer can appear in a bonus game.

In the bonus game there is a Global Multiplier Bar with the Multiplier levels x2, x3, x5 and x10, as well as 4 empty positions for Farmer or Gold Farmer symbols to fill. The Gold Farmer is collected and fills one position every spin. When a Farmer symbol lands, it is added to one of the empty positions. When 4 positions have been filled the Global Multiplier levels up to the next Multiplier level.

Each time the Global Multiplier levels up you are awarded 3 additional free spins.

The Global Multiplier level is applied to all wins, and to all Coins that are dug up in the grid.

The maximum achievable win in this game is 10,000 times your bet. The maximum win may be achieved by triggering specific combinations and/or features. When this amount is reached the game will display a message indicating the maximum win has been reached. The current round will then immediately end and your winnings will be awarded. In the event of disconnection, a previously started round that has been interrupted may be resumed immediately by starting the game again. The results of a completed round (where display of the visual result was interrupted) will only be re-displayed within the game for winning rounds, but all game rounds may be reviewed in Game History. Any amount wagered on an unfinished game will remain paused until you either complete the game or the game is void as a result of account inactivity or system maintenance. When an unfinished game is void, your bet will be refunded to your account. Any awards earned on an unfinished round will not be credited unless you resume and complete the game. Winnings on unfinished game rounds where the player cannot further influence the outcome of the game will be automatically credited to the player’s account after {payoutPeriod}. Game rounds will never be affected by unforeseen external errors due to hardware, bandwidth, network errors or similar. Game rounds will be either stored and completed by the player at a later time or they will be closed and the wager will be refunded to the player. If an incomplete game round has not been resumed within {rollbackPeriod}, the round will be rolled back and the wager will be refunded.
