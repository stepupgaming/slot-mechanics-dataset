When a winning combination occurs, all regular paying symbols of the type that were part of the winning combination are removed from the grid, and new ones drop down to fill the empty spaces.

COINWAYS™

When Bronze, Silver or Gold Coin symbols land in a formation that is equivalent to one of the predetermined Ways to win, CoinWays™ are formed. CoinWays™ must start at the leftmost reel and include Coin symbols on at least 3 adjacent reels. If there are Coins on reels 1, 2, 3 and 5, the CoinWays™ will only include the Coin values of the first 3 reels. CoinWays™ are activated after regular wins have been handled.

  • Bronze Coins can have the following values: 1x
  • Silver Coins can have the following values: 2x, 3x, 4x
  • Gold Coins can have the following values: 5x, 6x, 7x, 8x, 9x, 10x

When CoinWays™ activate, the Coin symbols add their values to the Coin Bar value for the reel they land on. Each reel’s Coin value will be displayed in the Coin Bar located outside of the grid. If there are multiple Coins on a reel, the Coin values are added together to determine the total Coin value of the reel.

Once the Coin symbol values have been added to the Coin Bar, the values in the Coin Bar will be multiplied from left to right. For example, if values in the Coin Bar are 2, 3, 2, 7, 3, the final CoinWays™ value will be 2x3x2x7x3=252x. The CoinWays™ value will be awarded as a cash prize that is multiplied by your bet to determine the final win. The Coin Bar will reset before the next spin.

Coin symbols can only land in the THUNDER REIGN, WRATH OF OLYMPUS and LAST ASCENSION bonuses.

Coin symbols can also land in SACRED FEATURESPINS™.

WAYS TO WIN

The specified requirements for a winning combination in the base game are also used during bonus features or free spins play unless otherwise stated. Each wager is eligible for all winning combinations unless otherwise stated.

You win if matching symbols appear on adjacent reels from left to right, starting with the leftmost reel. Each winning combination of matching symbols creates a winning way. The number of possible ways in this game is 1024. Please consult the paytable for the number of each symbol required to win.

After every win the winning symbols are removed and new ones drop in. This continues until there are no more new wins on the reels.

INTERRUPTED GAME

In the event of disconnection, a previously started round that has been interrupted may be resumed immediately by starting the game again. The results of a completed round (where display of the visual result was interrupted) will only be re-displayed within the game for winning rounds, but all game rounds may be reviewed in History. Any amount wagered on an unfinished game will remain paused until you either complete the game or the game is void as a result of account inactivity or system maintenance. When an unfinished game is void, your bet will be refunded to your account. Any awards earned on an unfinished round will not be credited unless you resume and complete the game. Winnings on unfinished game rounds where the player cannot further influence the outcome of the game will be automatically credited to the player's account after {payoutPeriod}. Game rounds that require additional player input to determine the outcome of the game will remain unfinished for {payoutPeriod}, after which a default choice will automatically be made in order to complete the round and credit any winnings to the player's account. Game rounds will never be affected by unforeseen external errors due to hardware, bandwidth, network errors or similar. Game rounds will be either stored and completed by the player at a later time or they will be closed and the wager will be refunded to the player. If an incomplete game round has not been resumed within {rollbackPeriod}, the round will be rolled back and the wager will be refunded.
