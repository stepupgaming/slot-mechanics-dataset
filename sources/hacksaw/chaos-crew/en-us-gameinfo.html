ABOUT THE GAME

Welcome to the gritty world of Cranky and Sketchy! Chaos Crew is a high volatility 5x5 grid paylines game loaded with multipliers! The maximum feature win for this game is 10,000 times your bet! The maximum win can be achieved in the Free Spins game mode.

CRANKY CAT

The Cranky Cat symbol is WILD and also a mystery multiplier that will multiply the current line win. Wins with the Cranky Cat symbol in the main game multiplies the line win with the multiplier shown. When the Cranky Cat symbol lands, it will take on one of the following multipliers: x2, x3 or x5. If you get multiple Cranky Cat symbols on the same win line, the multipliers will multiply each other!

The Cranky Cat symbol substitutes for all symbols in the base game except the FREE SPINS symbol.

FREE SPINS

If you land three Free Spin symbols, the game changes into free spin mode. The free spins mode starts with 3 spins. The free spins continue until you get three non-winning spins in a row. Every time you get a winning symbol, the number of free spins is reset to 3. The meter to the right of the grid displays the number of remaining spins.

A number is displayed above each reel. At the end of the free spins mode, the total win will equal the sum of all displayed numbers multiplied with the current bet level. All symbols affecting the multipliers are applied in the order left to right, top to bottom.

The symbols appearing in the free spins mode are described below:

Every time the Cranky Cat symbol appears, it will multiply the number shown above the current reel with the factor revealed inside the Cranky Cat symbol. The possible multipliers are x2, x3, x5, x10, x20.

Cranky Cat also has an Epic version. This symbol works the same way as the regular Cranky Cat symbol, but multiplies the value displayed above all reels with the factor shown! The possible multipliers are x2, x3, x5, x10, x20.

The Sketchy Skull symbol will add the number revealed inside the Sketchy Skull symbol to the current reel’s multiplier. The possible multipliers are +1, +2, +5, +10, +20.

The Epic Sketchy Skull symbol will add the number revealed inside the Sketchy Skull symbol to the factors shown above all reels! The possible multipliers are +1, +2, +5, +10, +20.

These symbols are non-winning.

When this amount is reached the game will display a message indicating the maximum win has been reached. The current round will then immediately end and your winnings will be awarded. INTERRUPTED GAME

In the event of disconnection, a previously started round that has been interrupted may be resumed immediately by starting the game again. The results of a completed round (where display of the visual result was interrupted) will only be re-displayed within the game for winning rounds, but all game rounds may be reviewed in History. Any amount wagered on an unfinished game will remain paused until you either complete the game or the game is void as a result of account inactivity or system maintenance. When an unfinished game is void, your bet will be refunded to your account. Any awards earned on an unfinished round will not be credited unless you resume and complete the game. Winnings on unfinished game rounds where the player cannot further influence the outcome of the game will be automatically credited to the player’s account after {payoutPeriod}. Game rounds will never be affected by unforeseen external errors due to hardware, bandwidth, network errors or similar. Game rounds will be either stored and completed by the player at a later time or they will be closed and the wager will be refunded to the player. If an incomplete game round has not been resumed within {rollbackPeriod}, the round will be rolled back and the wager will be refunded.
