FEATURES

RASCAL RESPIN MODE

When 3 or more Rascal symbols land on the same spin, they stick to the grid and trigger a Respin after all wins have been handled.

During the Respin only Rascal and Dead symbols can land. Dead symbols are non-paying symbols and have no other effect. All Rascal symbols that land during Respins become sticky. The Respin continues until no new Rascal symbols land or there are no more available positions. When Rascal symbols land in a square formation of 2x2, 3x3, 4x4 or 5x5 they merge to form a Colossal Rascal symbol. If a 5x5 Colossal Rascal symbol is formed, the Max Win is immediately awarded.

When a Respin is triggered, a Pendulum appears outside the grid with two Modes: Coin and Wild. The Pendulum randomly starts on one Mode then switches back and forth on each Respin, alternating between the two Modes. When the Respin sequence ends, the selected Mode is activated. On each Respin sequence, the Pendulum will start in a random Mode.

When Coin Mode activates, it turns all Rascal and Colossal Rascal symbols on the grid into Coins. All Coins are paid as a multiple of your bet.

Bronze Coins have the following values: 0.2x, 0.5x, 1x, 2x, 3x, 4x

Silver Coins have the following values: 5x, 10x, 15x, 20x

Gold Coins have the following values: 25x, 50x, 100x, 250x, 500x

Each Colossal Coin symbol has a Coin value and also receives an additional Multiplicative Multiplier. These two values are multiplied together to create a final bet Multiplier value for the Colossal Coin symbol.

2x2 Colossal Coin symbols have a minimum Coin value of 5x and an additional Multiplier value between x2, x3, x4, x5, x10, x15, x20, x25, x50, x100

3x3 Colossal Coin symbols have a minimum Coin value of 10x and an additional Multiplier value between x3, x4, x5, x10, x15, x20, x25, x50, x100

4x4 Colossal Coin symbols have a minimum Coin value of 25x and an additional Multiplier value between x4, x5, x10, x15, x20, x25, x50, x100

When Wild Mode activates, it turns all Rascal and Colossal Rascal symbols into Wild symbols. Wild symbols substitute for all symbols in the paytable.

All Colossal Wild symbols also receive an Additive Multiplier:

2x2 Colossal Wild symbols have values between 2x, 3x, 4x, 5x, 10x, 15x, 20x, 25x, 50x, 100x

3x3 Colossal Wild symbols have values between 3x, 4x, 5x, 10x, 15x, 20x, 25x, 50x, 100x

4x4 Colossal Wild symbols have values between 4x, 5x, 10x, 15x, 20x, 25x, 50x, 100x

When all Rascal symbols have turned into Wild symbols, a regular spin is triggered where all Wild symbols stick to the grid and regular paying symbols spin in. When Colossal Wild symbols participate in a winning combination, the value of the win is multiplied by the shown value. If more than one Colossal Wild symbol is part of the same winning combination, the values are first added together, then applied to the win.

Once a Pendulum Mode has been activated and wins have been awarded, the Respin sequence ends.

BONUS GAME - AFTER DARK

Activate this bonus with 10 free spins by landing 4 FS scatter symbols at the same time during the base game.

This bonus keeps the base game's mechanics. In addition, if less than 3 Rascal symbols land on a spin, those symbols are saved in a Popcorn Bucket outside of the grid until the end of the bonus. On the last free spin, all saved Rascal symbols are added to the grid. If 3 or more Rascal symbols are added to the grid, a Respin sequence is triggered. The maximum number of Rascal symbols that can be saved is 25.

Rascal symbols that trigger a Respin sequence or land during the Respin sequence will not be saved.

INTERRUPTED GAME

In the event of disconnection, a previously started round that has been interrupted may be resumed immediately by starting the game again. The results of a completed round (where display of the visual result was interrupted) will only be re-displayed within the game for winning rounds, but all game rounds may be reviewed in History. Any amount wagered on an unfinished game will remain paused until you either complete the game or the game is void as a result of account inactivity or system maintenance. When an unfinished game is void, your bet will be refunded to your account. Any awards earned on an unfinished round will not be credited unless you resume and complete the game. Winnings on unfinished game rounds where the player cannot further influence the outcome of the game will be automatically credited to the player’s account after {payoutPeriod}. Game rounds will never be affected by unforeseen external errors due to hardware, bandwidth, network errors or similar. Game rounds will be either stored and completed by the player at a later time or they will be closed and the wager will be refunded to the player. If an incomplete game round has not been resumed within {rollbackPeriod}, the round will be rolled back and the wager will be refunded.
