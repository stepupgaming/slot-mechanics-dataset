ABOUT THE GAME

Canny and Mona are dropping back in with a big bang! Drop’em is a 5-reel, 6-row Ways-win game with a special Drop symbol that will remove all symbols below it, so that new ones of a chosen type can drop in to fill the empty spaces! The max win in this game is 10,000 times your bet and the max amount of possible ways you can win is 7,776! The max win can be achieved in the base game, Drop Spins, High Drop Spins, and Wild Drop Spins game modes.

FEATURES

DROP SYMBOL

When one or more Drop symbols land, the Drop mechanic will activate after any winning combinations on the initial grid have been awarded.

Each Drop symbol will fall downward and out of the grid and remove all symbols below it. Any symbols above the Drop symbol will fall to the bottom of the reel.

The empty spaces on each reel will then be filled with the same randomly chosen symbol. In the base game, this symbol will be chosen from any of the paying symbols or the Wild symbol.

If the new symbols create a winning combination, that win will be awarded. If a winning combination created by the new symbols could also include symbols which have already been a part of a winning combination before the Drop mechanic activated, those symbols will also be included in the new winning combination.

DROP SPINS BONUS

Land 3 FS scatter symbols at the same time in the base game to trigger this feature with 10 free spins.

This bonus starts with all paying symbols and the Wild symbol in the pool of possible symbols that can be chosen by the Drop mechanic.

Land the FS symbol in the feature to reveal extra free spins and possibly get an UPGRADE that removes some symbols from the Drop mechanic pool. Each landed FS symbol can award +1, +2 or +3 extra free spins. When revealing an UPGRADE, between 1 to 10 (at most all remaining) paying symbols will be removed from the choice pool. The Wild symbol can never be removed from the pool.

HIGH DROP SPINS BONUS

Land 4 FS scatter symbols at the same time in the base game to trigger this feature with 10 free spins.

This bonus starts with only high-paying symbols and the Wild symbol in the pool of possible symbols that can be chosen by the Drop mechanic.

Land the FS symbol in the feature to reveal extra free spins and possibly get an UPGRADE that removes some symbols from the Drop mechanic pool. Each landed FS symbol can award +1, +2 or +3 extra free spins. When revealing an UPGRADE, between 1 to 5 (at most all remaining) paying symbols will be removed from the choice pool. The Wild symbol can never be removed from the pool.

WILD DROP SPINS BONUS

Land 5 FS scatter symbols at the same time in the base game to trigger this feature with 10 free spins.

This bonus has the Wild symbol as the only possible choice for the Drop mechanic!

Land the FS symbol in the feature to reveal extra free spins. Each landed FS symbol can award +1, +2 or +3 extra free spins.

MAX WIN

The maximum achievable win in this game is 10 000 times your bet. The maximum win may be achieved by triggering specific combinations and/or features. When this amount is reached the game will display a message indicating the maximum win has been reached. The current round will then immediately end and your winnings will be awarded. If this occurs during free spins and/or other bonus feature(s), the game will return to the main screen and any remaining free spins and/or other bonus feature(s) will be discarded.

INTERRUPTED GAME

In the event of disconnection, a previously started round that has been interrupted may be resumed immediately by starting the game again. The results of a completed round (where display of the visual result was interrupted) will only be re-displayed within the game for winning rounds, but all game rounds may be reviewed in History. Any amount wagered on an unfinished game will remain paused until you either complete the game or the game is void as a result of account inactivity or system maintenance. When an unfinished game is void, your bet will be refunded to your account. Any awards earned on an unfinished round will not be credited unless you resume and complete the game. Winnings on unfinished game rounds where the player cannot further influence the outcome of the game will be automatically credited to the player’s account after {payoutPeriod}. Game rounds will never be affected by unforeseen external errors due to hardware, bandwidth, network errors or similar. Game rounds will be either stored and completed by the player at a later time or they will be closed and the wager will be refunded to the player. If an incomplete game round has not been resumed within {rollbackPeriod}, the round will be rolled back and the wager will be refunded.
