Game Features
Wild Transform
Match the symbol in the top reel and the symbol underneath on
the same reel to transform both into a Wild symbol.


xNudge Wild
Stacked Wild symbol in the bottom reel that will always nudge to
be fully visible, each nudge increased a wild multiplier by 1. Get
a 2nd chance with an even higher multiplier if you don’t win on it
the first time...


xWays & Infectious xWays
You’ve seen it before - xWays reveals 2-3 of the same symbol.
Infectious xWays symbol will affect and multiply all symbols of the
revealed type for massive wins.


Reel Split
Reel split will double all symbols above it on the main reel. It
then vanishes, causing a bottom reel collapse for new symbols to
appear.
