## xBet®
At an extra cost per spin, the player gets an increased chance of getting into the Bonus Modes. The way this happens varies from game to game. The payout for each symbol is not affected.

## xNudge®
xNudge®:  A simple yet effective feature that turns any game into a massive potential bearing title! xNudge works alongside wild reels, wherein landing a wild in view has the potential to increase the multiplier attached, as the wild nudges to fill the entire reel. If the wild is not centred in the reel, it will either nudge up or down, incrementing its multiplier by 1 for each nudge.

## xNudge® Wilds
There are 3 types of xNudge® Wilds which land as a stacked symbol and always nudge to be fully visible. A random multiplier value updates at the bottom of xNudge® Wild when it’s fully visible and adds to the xNudge® Wild multiplier value, respectively.

xNudge® Wilds have different nudge multiplier value:

- Joshua xNudge® Wild - Each nudge increases the win multiplier value by +1 and the maximum multiplier value can be awarded is 8x.

- Jason xNudge® Wild - Each nudge increases the win multiplier value by +2 and the maximum multiplier value can be awarded is 21x.

- Hyper xNudge® Wild - Each nudge increases the win multiplier value by +5 and the maximum multiplier value can be awarded is 51x.

## xNudge® Meter
The xNudge® Meter summarizes the overall xNudge® multiplier values on the winning symbols.
