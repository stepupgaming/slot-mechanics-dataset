## Infectious xWays®
Any xWays symbols that appear will reveal the same symbol, and if the symbol revealed is already visible on the reels, each in view will be ‘infected’ and will expand as if they are xWays – producing additional ways to win.

## xBet®
At an extra cost per spin, the player gets an increased chance of getting into the Bonus Modes. The way this happens varies from game to game. The payout for each symbol is not affected.

## xBomb®
An xBomb Wild symbol substitutes any symbol except for the Bonus symbols. An exploding xBomb Wild removes adjacent symbols except for Bonus symbols and will increase the win multiplier by one for the next collapse.

All xBomb Wilds will explode before the next collapse, except when the Wild Mining feature is triggered. An xBomb Wild will explode when there is a win, no matter if it’s a part of the winning combination or not. It will explode and trigger a new collapse if there isn’t a win, and wild Mining feature is not triggered.

## xNudge®
xNudge®:  A simple yet effective feature that turns any game into a massive potential bearing title! xNudge works alongside wild reels, wherein landing a wild in view has the potential to increase the multiplier attached, as the wild nudges to fill the entire reel. If the wild is not centred in the reel, it will either nudge up or down, incrementing its multiplier by 1 for each nudge. 

## Reel xSplit™
Reel xSplit® is a brand new xMechanic featured in Stockholm Syndrome. It has made cameos in San Quentin and Tombstone RIP but has recently been trademarked. Reel xSplit® is a variation of xSplit® whereby instead of a row of symbols being split, a whole reel of symbols is split. This is a very powerful mechanic that can change the game by increasing win ways. 

## Main Game
A 3-4-3-4-3 reel area in base game with 432 win ways.

Any winning symbols will explode and be removed. New symbols fall into place which may award additional wins.

During the game round, a randomly chosen character symbol gets a win multiplier: x2, x3, x4, ×5 or x10.

## Con Man Wild
Triggered when the Con Man Wild fully lands on reel 3. The bottom position on reel 3 gets unlocked and becomes part of the Con Man Wild.

A random character symbol (except the highest paying symbol) will be chosen and all of its instances will be transformed to a Wild.

Main Game: When the Con Man Wild lands partly from the top it does not get removed by winning combinations.

## xBomb® Wild
An xBomb® Wild symbol substitutes for any symbol except Scatter symbols.

Main Game: An exploding xBomb® Wild removes adjacent symbols except for Scatter and Wild symbols increasing the win multiplier by one for the next collapse. All xBombs will explode before the next collapse.

Bonus Modes: xBomb Wild® will only increase the win multiplier.

## POLIS Feature
Triggered in main game only when POLIS symbols land in the same row sequentially.

First 4 positions will get locked coin values with random multipliers: x5, x10, x25, x100, x250, x1000, x5000 or a Max Win symbol. The 5th position can get up to 3 keys. Each key will open one of the locked coin values or the Max Win.

All the unlocked coin values will be added and multiplied by the base bet for the win.

## SOS Feature
Triggered when SOS symbols land in the same row sequentially.

Symbol ‘O’ will be transformed to xBomb® Wild.

SOS feature will only trigger in the main game in case of no win and no avalanche. During bonus mode it will always trigger.

## PISS Feature
Triggered when PISS symbols land in the same column sequentially.

All these symbols will be transformed to xBomb® Wild.

PISS feature will only trigger in the main game in case of no win and no avalanche. During bonus mode it will always trigger.

## Respin
Landing 2 Scatters with no avalanche will trigger a respin on the bottom position of reel 3 where a third Scatter might land.

## Hostage Spins
Landing 3 Scatter symbols in the base game will trigger 7 Hostage Spins. The bottom position on reel 3 gets unlocked.

Every time a full Con Man Wild lands, it will increase the Con Man Wild win multiplier by +1 and choose a character symbol in a predetermined order and upgrade it to the highest paying character symbol for the remaining spins.

First time the Con Man Wild lands, lowest paying character symbol is chosen, second time Con Man Wild lands second lowest character symbol is chosen, and so on.

Landing full Con Man Wild will award +1 spin.

xBomb® multiplier will be sticky throughout the Hostage Spins.

A Scatter symbol award +1 extra spin during the Hostage Spins.

## Syndrome Spins
Landing 4 Scatter symbols in base game will trigger 8 Syndrome Spins.

A reel setup of 3-4-4-4-4-3 during this mode.

Con Man Wild can land on reel 3 and 4. When a part of the Wild lands on the reels, it will begin to nudge up or down until it is fully visible on the entire reel.

Character symbols will be collected from 4 middle reels only when Con Man Wild lands. Character symbols will be collected twice in case of 2 Con Man Wilds. Collect meter can go beyond 5, when all collect meters are full - Syndrome feature will be triggered making the middle reels special in the following way:

Reel 3 Wild:
Reel 3 will be covered by a Wild symbol with a win multiplier depending on the collected symbol displayed below reel 3. Starting multiplier will be 2 which will increment by +1 for each extra collected symbol beyond 5.

Reel 4 Infectious xWays®:
A new position opens up and reveals a random symbol of size 2 and affect all occurrences of that symbol on the reels to become same in size. Collected symbol below reel 4 will increase the Ways size by +1 for each extra collected symbol beyond 5.

Reel 2 & 5 Reel xSplit™:
Each symbol on the reel will be split into 2. The collected symbol below reel 2 and 5 will increase the split size by +1 for each extra collected symbol beyond 5 on their respective reels.

Landing full Con Man Wild will award +1 spin. A Scatter symbol award +1 extra spin during Syndrome Spins.

xBomb® multiplier will be sticky throughout the Syndrome Spins.
