Game description
Propaganda 2 is a 6 row, 6 column cluster game with increasing global multiplier, dropping symbols, and feature activations.
The game is a cluster paying game.
A winning cluster consists of 5 or more identical symbols connected vertically or horizontally. For each symbol type, only the largest winning cluster is paid in each win evaluation.
The RTP is the same throughout the game and the RTP is defined in the game rules.
3 or more Bonus symbols trigger the Bonus game with Bonus drops.
If at least one Bonus symbol is a Super Bonus symbol, the Super Bonus game is awarded.
In the Super Bonus all features are activated.

The Mask symbol is collected when a winning cluster is adjacent to a Mask symbol.
Collecting 6 Mask symbols triggers the Drop Bonus game.
The Drop Bonus game plays with 3 spins. Landing one or more symbols resets the spin counter to 3.
The game view displays the player balance, bet level, and win amount.
All values remain visible throughout the session in both landscape and portrait orientations.
Wild symbols substitute for all payout symbols. A cluster consisting only of Wild symbols pays as the highest-paying symbol.
3 Bonus symbols trigger the Bonus game with 7 Bonus drops.
If a Super Bonus symbol appears during the Bonus game, the game upgrades to the Super Bonus game and 2 additional Bonus drops are awarded.
A Mask symbol activates when adjacent to a winning cluster. Collecting 6 Mask symbols triggers the Drop Bonus.
A Wild Strike feature symbol activates when adjacent to a winning cluster. It adds 2, 3, 4, or 5 Wild symbols to the grid and then becomes a Wild symbol.
A Heart feature symbol activates when adjacent to a winning cluster. The Heart symbol then becomes the selected payout symbol type.
The Upgrade symbol upgrades all payout symbols to a higher payout symbol type on the game grid and then becomes the payout symbol type.
The Collect symbol selects a symbol area on the grid, gathers all symbols within the selected area into a single cluster, and then becomes the payout symbol type.
In the Bonus game, the Add Bonus Drop symbol awards 1 additional Bonus drop.
